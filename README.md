# Facial Recognition Attendance System

A Flask-based Facial Recognition Attendance System that uses Python, OpenCV, and face recognition to automate attendance.

## 📌 Project Overview

The Facial Recognition Attendance System is designed to recognize registered faces through a camera and automatically record attendance.

The system provides a simple web interface where users can take attendance and view attendance history.

## ✨ Features

- Real-time face recognition
- Automated attendance marking
- Attendance history viewing
- Face registration using images
- Face encoding for recognition
- Flask-based web interface
- Attendance stored in CSV format
- Separate functionality for managing registered users

## 🛠️ Technologies Used

- **Python**
- **Flask**
- **OpenCV**
- **face_recognition**
- **NumPy**
- **HTML**
- **CSS**
- **Jinja2**
- **Anaconda**
